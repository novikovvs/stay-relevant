# Stay Relevant

Тренажёр подготовки на Flutter для macOS. Тематические блоки хранятся как `blocks/<id>.json`, метаданные каталога — в `blocks/catalog.json` и появляются в приложении из каталога GitHub. Выбранный блок скачивается в локальное хранилище; ответы, интервальные повторы и прогресс работают офлайн.

## Запуск

```sh
./run_macos.sh
```

## Формат блока

Каждый JSON-файл в корне папки `blocks/` — отдельный блок; `catalog.json` содержит только метаданные карточек каталога. Обновляй его вместе с блоком. Приложение сверяет записи каталога с файлами в GitHub, а содержимое скачивает только после выбора. Формат блока сохраняет единое описание вопросов:

```json
{
  "schema_version": "1.0",
  "id": "golang_mid_interview_questions",
  "title": "Вопросы для собеседования по Go — уровень middle",
  "language": "ru",
  "questions": [
    {
      "id": "unique-question-id",
      "question": "Текст вопроса",
      "answer": "Развёрнутый правильный ответ",
      "distractors": ["Правдоподобный ответ 1", "Ответ 2", "Ответ 3"],
      "category": "Горутины",
      "difficulty": "medium",
      "sources": ["https://go.dev/ref/spec"]
    }
  ]
}
```

Папка `blocks/` сканируется через GitHub Contents API. При выборе приложение скачивает JSON, проверяет обязательные поля, уникальность ID вопросов и ID блока, затем сохраняет его в `~/Library/Application Support/Stay Relevant/blocks/`. Не храните вложенные каталоги внутри `blocks/`: каждый непосредственный `.json` файл — один блок.

Прогресс находится отдельно в `~/Library/Application Support/Stay Relevant/progress.json`. Три верных ответа подряд открывают интервалы повторения 1, 3, 7, 14 и 30 дней.
