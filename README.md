# Go Fluent

macOS-приложение на Flutter. JSON-базы входят в приложение как assets; викторина, случайный выбор, интервальное повторение и локальное сохранение прогресса выполняются на устройстве. Go-сервер не нужен.

## Запуск

```sh
./run_macos.sh
```

Скрипт запускает Flutter-клиент напрямую, без отдельного сервера.

Прогресс хранится в `~/Library/Application Support/Go Fluent/progress.json`.

## Добавление базы

1. Положи JSON-файл в `assets/questions/`.
2. Добавь путь к нему в `assets/questions/index.json`.
3. Пересобери приложение.

Формат базы: объект с `title` и массивом `questions`. Для каждой карточки обязательны уникальный `id`, `question`, развёрнутый `answer` и три `distractors`; `category`, `difficulty` и `sources` показываются или сохраняются как справочные поля.

На каждый вопрос требуется 3 правильных ответа подряд. После обучения интервалы составляют 1, 3, 7, 14 и 30 дней. Последние 20 показанных карточек сохраняются между перезапусками и временно пропускаются, если в очереди есть другие доступные вопросы.
